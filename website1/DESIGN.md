## Brand & Style

This design system establishes a high-trust, polished, and contemporary aesthetic tailored for an emerging web developer bridging academic rigor with modern product engineering. The emotional tone projects capability, thoughtful craftsmanship, and clarity over unnecessary flash. 

The visual style is rooted in modern editorial minimalism infused with clean architectural geometry:
- **Atmosphere**: Crisp, composed, organized, and focused on legibility and artifact display.
- **Hierarchy**: Strict structural framing, generous breathing room, and intentional typography that prioritizes readability across project case studies, academic milestones, and dynamic code demonstrations.
- **Micro-details**: Restrained accents, soft diffused borders, and tactile yet subtle surface transitions that signal modern front-end acumen without distracting from content.

## Colors

The palette balances authoritative structure with an approachable, engineering-forward accent.

- **Primary (`#172B4D` - Deep Navy)**: Forms the structural foundation. Reserved for primary branding, structural navigation elements, impactful titles, and primary emphasis anchors.
- **Secondary (`#3D8B83` - Teal Green)**: Acts as the interactive voice. Applied to focused interactive triggers, prominent CTAs, active status markers, link states, and key metric indicators.
- **Tertiary (`#2D3748` / `#4A5568` - Slate Gray)**: Provides high-contrast, effortless readability for long-form narrative, technical project descriptions, and detailed experience timelines.
- **Neutral Canvas (`#F5F7FA` - Soft Light Gray)**: Creates alternate section cadence, breaking continuous white backgrounds into structured thematic regions (e.g., project grids, academic credentials).
- **Surface Pure (`#FFFFFF`)**: Base color for elevated card planes, input fields, and foreground containers to achieve crisp layer separation.
- **Borders & Dividers (`#E2E8F0`)**: Subtle containment lines ensuring accessibility and crisp container separation without visual clutter.

## Typography

The typography leverages `Inter` across all text tiers to maintain clean geometric rhythm, exceptional legibility, and technical precision.

- **Headlines**: Set in dark navy (`#172B4D`) with tight negative tracking (`-0.01em` to `-0.025em`) to emphasize weight and modern editorial presence.
- **Body Content**: Rendered in dark slate gray (`#2D3748` for primary paragraphs; `#4A5568` for secondary descriptions) with relaxed line heights (`1.6x` to `1.75x`) to reduce visual fatigue across case study walk-throughs.
- **Labels & Tags**: Tuned with slightly elevated weights (`500` to `600`) and subtle positive letter spacing (`0.025em` to `0.05em`) for quick visual scanning of tech stack badges and timeline metadata.

## Layout & Spacing

The layout model is anchored by a structured 12-column responsive fluid grid with strict content constraint:
- **Maximum Width**: Container max-width is capped at `1200px` to maintain optimal line-length and presentation balance.
- **Breakpoints**:
  - `Mobile` (< 768px): 4-column layout, `gutter-sm` (1rem / 16px), `margin` (1.5rem / 24px).
  - `Tablet` (768px - 1024px): 8-column layout, `gutter` (1.5rem / 24px), `margin-md` (2.5rem / 40px).
  - `Desktop` (> 1024px): 12-column layout, `gutter-lg` (2rem / 32px), `margin-lg` (4rem / 64px).
- **Rhythm**: Alternating vertical page rhythm uses `space-2xl` (64px) between sections and `space-xl` (40px) between card clusters and timeline items.

## Elevation & Depth

Visual hierarchy uses a refined combination of pure white surface tiers, subtle boundary strokes, and diffused ambient drop shadows tinted with navy undertones:

- **Level 0 (Flat)**: Natural flow elements sitting directly on the canvas (`#F5F7FA` or `#FFFFFF`).
- **Level 1 (Card Rest)**: Applied to project cards, skill groups, and form containers. `box-shadow: 0 1px 3px rgba(23, 43, 77, 0.05), 0 1px 2px rgba(23, 43, 77, 0.03)` with a hairline border (`1px solid #E2E8F0`).
- **Level 2 (Interactive Hover / Floating Elements)**: Used when hovering project cards or focusing interactive modules. `box-shadow: 0 10px 25px -5px rgba(23, 43, 77, 0.08), 0 8px 10px -6px rgba(23, 43, 77, 0.04)`. Card translation lifts `-2px` on the Y-axis.
- **Level 3 (Modals / Navbars / Overlays)**: High priority floating navigation bars. `box-shadow: 0 20px 25px -5px rgba(23, 43, 77, 0.08), 0 10px 10px -5px rgba(23, 43, 77, 0.02)`. Navbars apply `backdrop-filter: blur(12px)` over `rgba(255, 255, 255, 0.88)`.

## Shapes

The design system implements a `2` (Rounded) geometry profile, striking a balanced harmony between architectural structure and human-friendly softness:
- **Base Components**: Cards, standard input fields, modal overlays, and code blocks use an `8px` (`0.5rem`) corner radius.
- **Medium Elements**: Inner nested card media, callout panels, and large preview frames use `16px` (`1rem`).
- **Pills / Badges**: Skill chips, category tags, interactive tab capsules, and small action buttons use fully pill-shaped rounding (`9999px`) to visually delineate them from layout grids and cards.

## Components

### Buttons
- **Primary**: Solid teal green background (`#3D8B83`), white text (`#FFFFFF`), `font-weight: 600`, pill-shaped or `rounded-md` (8px). Hover state transitions background to `#32726B` with a subtle elevation shift. Focus outlines display a `2px` ring in `#3D8B83` with a `2px` offset.
- **Secondary / Ghost**: Deep navy outline (`1.5px solid #172B4D`) with navy text (`#172B4D`) on transparent background. Hover state fills surface with subtle navy tint (`rgba(23, 43, 77, 0.04)`).
- **Subtle**: Transparent base with dark slate text (`#2D3748`). Hover transitions to light gray background (`#EDF2F7`).

### Badges & Tags (Skills / Tech Stack)
- Compact pill-shaped containers (`padding: 0.25rem 0.75rem`).
- **Neutral Stack Tag**: Light background (`#EDF2F7`), slate text (`#2D3748`), font size `label-sm`.
- **Accent Highlight Tag**: Soft teal background (`rgba(61, 139, 131, 0.1)`), deep teal text (`#2B6660`), font size `label-sm`. Hairline border in `rgba(61, 139, 131, 0.2)`.

### Cards (Project & Case Studies)
- Built on a solid pure white surface (`#FFFFFF`), wrapped in a `1px solid #E2E8F0` border with Level 1 elevation.
- Includes a media preview slot at top (`rounded-t-lg`), project metadata and tags centrally grouped, and an action link area anchored to the bottom.
- Hover triggers smooth transition to Level 2 elevation and card upward translation.

### Timeline (Education & Career)
- Continuous vertical spine rendered in `2px solid #E2E8F0`.
- **Node**: A `12px` circle with a `3px` white border and solid `#3D8B83` teal center.
- **Content Blocks**: Offset to the right with role/degree in navy (`#172B4D`), institution/company in teal (`#3D8B83`), date tags in slate gray (`#4A5568`), and body copy providing bullet achievements.

### Input Fields & Forms
- Inset field with `#FFFFFF` background, `1px solid #CBD5E0` border, `8px` corner radius, and `padding: 0.75rem 1rem`.
- **Placeholder**: Slate muted (`#A0AEC0`).
- **Focus**: Border shifts to teal (`#3D8B83`) with an exterior ring `0 0 0 3px rgba(61, 139, 131, 0.2)`.
